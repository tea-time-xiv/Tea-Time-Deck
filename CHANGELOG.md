# Changelog

Each released version gets a section here. The publish pipeline copies the section for the
version being released into the Tea Time plugin repo, which is what the in-game changelog
(`/xlplugins` -> Changelog) shows. Dalamud renders that text as plain text, so keep it to
short `-` bullets: no tables, no links, no bold.

Versions before 0.3.0.0 predate this file; see the GitHub releases for those.

## 0.4.0.0

- Glamourer browser gained a Reset key.
- The Stream Deck half of the plugin is easier to find: the game side says out loud that
  there is a second half to install, and where to get it.

## 0.3.0.0

- The Stream Deck plugin download is linked from in-game (/ttd).
- The deck half is covered by unit tests.
